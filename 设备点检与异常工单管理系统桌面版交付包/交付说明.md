# 交付说明

## 一、项目简介

本交付包是「设备点检与异常工单管理系统」的桌面版实现。系统面向中小制造企业的设备日常点检场景，覆盖设备台账、点检标准、每日点检、异常判定、自动开单、维修闭环、统计报表与操作追溯。

技术形态：C# WinForms 单窗口程序 + SQLite 单文件数据库（通过系统自带的 `winsqlite3.dll` 以 P/Invoke 访问），不需要安装数据库服务，不需要 Office，**不依赖 MATLAB**。整个系统的数据就是一个 `inspection.db` 文件，复制即迁移，备份即拷贝。

## 二、为什么换题

原题目「线阵工业相机安装支架轻量化优化系统」的核心是悬臂梁挠度与转角的力学求解，MATLAB 子进程负责数值计算，数据库只承担记录职责；对本课程“数据管理、数据库是重点”的指向支撑偏弱，而且本机没有 MATLAB，主链路一直处于“待联调”状态。

新题目把重点放在数据本身：七张表的模型设计、外键与唯一约束、索引与视图、事务内的“录入—判定—开单—刷新计划”一致性、工单状态机、统计口径与可追溯日志。这些正是课程要求的数据库能力，演示与答辩也更容易讲清楚。

原相机支架交付包保留在上一级目录，未做改动，可作为对照。

## 四、快速开始

1. 解压整个文件夹到本地（路径不要含特殊符号）。
2. 双击 `运行程序\设备点检系统.exe`。
3. 首次运行会在 `运行程序\数据库\` 下创建或打开 `inspection.db`；若该目录不可写，自动回退到 `%LOCALAPPDATA%\InspectionSystem\`，状态栏会显示实际数据库路径。
4. 想恢复初始演示数据：菜单「数据 → 重置示例数据」，确认后重启程序。

## 五、自检与验收对照

### 5.1 自动自检

自检入口编译为控制台程序后执行（源码相同，仅入口不同）：

```
csc /nologo /codepage:65001 /target:exe /out:selftest.exe /main:Inspection.Program ^
    Db.cs Store.cs MainForm.cs Dialogs.cs SelfTest.cs Program.cs ^
    /r:System.Windows.Forms.dll /r:System.Drawing.dll
selftest.exe --selftest
```

期望输出末尾为 `结果：通过 47 项，失败 0 项。`，退出码 0；报告同时写入 exe 同目录的 `自检报告.txt`。自检覆盖种子数据、查询筛选、判定边界与紧急阈值、自动开单与去重、计划自动完成、工单状态机、计划生成幂等、统计口径、CSV 导出、备份与删除保护。

## 六、数据库设计要点

- 七张表：`equipment`、`check_item`、`operator`、`check_plan`、`check_record`、`work_order`、`audit_log`。
- 六个索引：计划日期、计划状态、记录所属计划、记录所属点检项、工单状态、工单点检项。
- 一个视图：`v_equipment_overview`，汇总每台设备的点检项数、最近点检时间、未关闭工单数。
- 关键约束：`equipment.code`、`operator.name`、`work_order.order_no` 唯一；`UNIQUE(plan_date, equipment_id)` 防止重复建计划；`UNIQUE(plan_id, check_item_id)` 防止同一计划同一项重复记录；`CHECK(lower <= upper)`；外键开启 `ON DELETE CASCADE` 与 `ON DELETE RESTRICT`。
- 一致性：录入读数在单个事务内完成“写记录 → 判异常 → 自动开单（按点检项去重）→ 刷新计划状态”，任一步失败整体回滚。
- 可追溯：所有关键写操作写入 `audit_log`，界面保留最近 200 条。

详细字段、SQL 与规则见《02 详细设计文档》第 3、4 章。

## 七、环境要求

- Windows 7 及以上，.NET Framework 4.x（系统自带）。
- 无需安装 SQLite、MATLAB、Office 或任何数据库服务。
- 单机、单用户使用；数据库文件请勿放在网络共享盘上并发写入。

## 八、常见问题

- **打开后没有数据**：确认状态栏的数据库路径；首次运行会自动建库并写入示例数据。
- **提示数据库被占用**：关闭其他正在运行的本程序实例后重试。
- **想清空重来**：菜单「数据 → 重置示例数据」会删除并重建全部表，然后重新写入示例数据。
- **换电脑**：复制整个 `运行程序` 文件夹即可，数据库随文件夹迁移。
- **字体**：文档使用微软雅黑，Windows 7 以上默认具备；若系统缺失，Word 会以相近字体替代，不影响内容。
